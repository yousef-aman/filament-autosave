# Changelog

## 1.0.0 - 2026-04-15

- Initial release
- Autosave for Edit Pages with debounce
- Visual status indicator (saving, saved, error)
- Global mode via plugin
- Per-page configuration (debounce, excluded fields, enable/disable)
- Lifecycle hooks (beforeAutosave, afterAutosave)
- Dark mode support
- Translation support
